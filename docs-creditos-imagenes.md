# Créditos de fotografías del menú

Las fotografías pueden guardarse localmente en `img/products/` para que la tienda no dependa de descargar el archivo de imagen en cada visita. Los campos `imageCredit` e `imageSource` de `js/data.js` conservan la atribución y el enlace a la ficha de Wikimedia Commons cuando se utiliza una obra de terceros. Las fotos son **referenciales** y no sustituyen una fotografía propia o validada por el negocio: algunas representan preparaciones similares, no el plato exacto ofrecido por Pelícanos Bros.

## Notas

- Se muestran las atribuciones debajo de las fotografías y se enlaza la ficha de cada archivo.
- Los archivos de imagen se cargan desde `img/products/`; se debe copiar allí la fotografía correspondiente. La consulta de las fichas de fuente requiere conexión a Internet.
- Si una imagen no carga, la tarjeta muestra un marcador visual alternativo y conserva sus datos y acciones.
- Para el Pelícano mixto se reserva la ruta local `img/products/mixto.jpg`. La persona que incorpore la fotografía debe completar `imageCredit` e `imageSource` si utiliza una obra de terceros; si es propia, puede indicar "Fotografía propia" y dejar el enlace vacío.
- La fotografía del agua corresponde a otra marca y a una botella de 33 cl; se usa únicamente como referencia visual, no como prueba de la presentación de 625 ml ofrecida en el menú.
- Antes de publicar, revisar de nuevo las condiciones de cada ficha y conservar esta atribución. En caso de adaptar una obra CC BY-SA, distribuir la adaptación bajo la misma licencia o una compatible.
